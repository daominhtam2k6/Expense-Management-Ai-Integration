# Kết quả kiểm tra dịch vụ và trình duyệt

Các file JSON ghi kết quả theo ngày trong tên file; chúng được giữ nguyên nội dung khi chuyển vị trí. Mở `test-report.md` ở thư mục cha để xem phạm vi của từng lần kiểm tra. Ảnh browser thô nằm tại `.tools/test-results/` ở gốc dự án. Công cụ tái hiện nằm trong `tools/`; lần sắp xếp thư mục này không gọi dịch vụ hoặc chạy lại kiểm thử.
