# Sơ đồ tuần tự

- `methods/`: các sơ đồ theo thao tác từ bộ tài liệu thiết kế.
- `account/`: các sơ đồ tài khoản từ bộ SRS.
- `use-cases/`: nguồn theo UC001–UC011 chọn từ .tools/document-assets, tách thành từng file; có các PNG sẵn có được sao chép cùng nhóm.

Danh sách file và ảnh: xem trực tiếp từng thư mục. Nguồn .puml chưa có PNG tương ứng có thể render sau; lần này chỉ sắp xếp và chọn file có sẵn.
