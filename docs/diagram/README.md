Giữ nguồn PlantUML và ảnh cùng nhóm. Các nguồn theo use case được chọn từ .tools/document-assets; không dùng ảnh preview trang Word làm sơ đồ riêng. File nguồn chưa có ảnh tương ứng có thể render hoặc thêm ảnh thủ công sau. Screenflow và ảnh màn hình của tài liệu 06 nằm trong [software/design/screenflow](../software/design/screenflow/).
