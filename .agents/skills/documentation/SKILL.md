# Viết tài liệu

## Đầu vào

Yêu cầu hiện tại, file liên quan, phạm vi được sửa và kết quả mong muốn. Xem [cấu trúc tài liệu](../../../docs/README.md). Prompt gợi ý: [14-viet-bao-cao-va-tai-lieu.md](../../../docs/prompt-library/14-viet-bao-cao-va-tai-lieu.md).

## Cách thực hiện

1. Đọc nguồn và xác định người đọc, file cần sửa, phần phải giữ.
2. Viết mục tiêu, nội dung, ví dụ và bước thực hiện rõ; dùng thuật ngữ/ID nhất quán.
3. Markdown vào docs/requirements/ hoặc docs/software/; prompt vào docs/prompt-library/; Word/PDF vào docs/archive/.
4. Khi chỉnh Word, giữ styles/caption/mục lục, nguồn ảnh; xuất preview để kiểm tra bố cục nếu có công cụ.
5. Kiểm tra link và nội dung; không tự tạo số liệu test, lịch sử sử dụng hoặc sửa nghiệp vụ để khớp tài liệu.

## Đầu ra

Tài liệu được giao; file trung gian chỉ tạo ở nơi nhiệm vụ cho phép.

## Hoàn tất

Kết quả đáp ứng yêu cầu, có đường dẫn và cách kiểm tra phù hợp. Nêu điều chưa rõ hoặc chưa kiểm tra; giữ nguyên file/môi trường ngoài phạm vi.
