# Code Review

Review without editing code. Inspect the diff or requested scope plus relevant requirements and architecture. Classify findings as CRITICAL, HIGH, MEDIUM, or LOW; include file/line evidence, impact, and remediation. Distinguish confirmed defects from risks or documentation gaps. Record results in `docs/code-review.md` and keep “no findings” distinct from “not checked.”
